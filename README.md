# 기후동행카드 정책 효과 분석 (SQL)

서울시가 2024년 1월 도입한 기후동행카드(월 65,000원으로 지하철·버스·따릉이 무제한)가 대중교통 이용량에 실제로 영향을 줬는지, 그리고 이 정책을 다른 지역으로 넓힐 필요가 있는지를 SQL로 분석한 프로젝트. 공개 데이터를 DBeaver로 SQLite에 올려 쿼리로 분석했다.

## 분석 질문
- 기후동행카드 시행 전후로 서울 지하철 이용량이 달라졌나
- 계절 효과를 걷어낸 순수 정책 효과는 얼마나 되나
- 다른 지역은 교통비 부담이 얼마나 큰가, 정책을 확대한다면 어디부터인가

## 사용 데이터 (4개 테이블)
- subway_usage: 지하철 일별 승하차 (2022~2026)
- climate_card: 기후동행카드 월별 활성 카드 수
- transport_cost: 시도별 월 교통비 구간 비율
- population: 시도별 인구

## 분석 내용 (쿼리 9개)
- 월별 이용량 추이와 시행 전후 연간 비교로 정책 효과를 수치화
- 활성 카드 수와 이용량을 JOIN해 보급과 이용의 연관성 확인
- 작년 같은 달과 비교(YoY)해 계절 효과를 제거한 순수 정책 효과 측정
- 노선별 증감을 CASE로 나눠 비교
- 시도별 교통비 고부담 비율을 비교하고 인구와 결합해 정책 확대 우선순위 지역 도출

## 결과
2024년 2월 이후 서울 지하철 이용량이 눈에 띄게 늘었고 2025년까지 증가세가 이어졌다. 다른 지역도 교통비 고부담 비율이 높은 곳이 있어, 인구 규모와 함께 보면 정책 확대를 우선 검토할 지역을 추려낼 수 있었다.
